# Support

Use the [GitHub issue tracker](https://github.com/Meauxsoft/mocontext/issues)
for reproducible bugs, client-configuration problems, documentation corrections,
and feature requests.

Before filing an issue:

1. Install the latest public Mo-Search release.
2. Open <http://127.0.0.1:43210/v1/health> and confirm that MoContext responds.
3. Review [Troubleshooting](docs/troubleshooting.md).
4. Search existing issues.

Include the Mo-Search/MoContext version, Windows version, AI client and version,
expected behavior, actual behavior, and concise reproduction steps.

GitHub issues are public. Redact usernames, personal paths, file contents,
search queries, session identifiers, tokens, and other sensitive information.
For private questions, licensing questions, or a diagnostic that cannot be
safely posted, email
[Questions@meauxsoft.com](mailto:Questions@meauxsoft.com).

Suspected vulnerabilities follow [SECURITY.md](SECURITY.md), not the public
issue tracker.
